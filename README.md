# まる | 日本株の学びと記録（Streamlit）

## ローカル実行
```bash
pip install -r requirements.txt
streamlit run app.py
```

## 変更しやすい場所
- リンク: content_config.yaml
- note埋め込み: embeds/note_embeds.html
- Shopify埋め込み: embeds/shopify_buy_button.html
- 見た目: assets/style.css
